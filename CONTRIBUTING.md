# Contributing

Use Python 3.12 and PostgreSQL 16 with the setup in [README](README.md). Keep fixtures original and synthetic; do not submit private customer data, credentials or employer code.

For changes to policy, review provenance or worker ownership, add a focused behavioral regression and run `make verify`. Run `make browser` for workflow changes, with `BROWSER_EVIDENCE_DIR` pointing to a writable artifact directory.

Describe the concrete behavior changed and the checks actually run. Disclose substantial AI assistance. Keep real commit dates and preserve third-party license notices.
